00 · Overview

An AI accountability system for fat loss.

BodyOps helps a user reach a target weight through meal-photo logging, weight tracking, progressive-overload workouts, daily missions, smart reminders, and AI coaching. This document is the engineering handoff: information architecture, component inventory, UX rationale, and responsive behavior. All screens are mid-fidelity grayscale wireframes — no color has been committed yet.

Primary user

Male, 30, software engineer. 107 kg → 77 kg over ~6 months. Trains 5–6 days/week. Wants simplicity, actionable guidance, and zero manual data entry.

Design principles
  • Progress first — every screen reinforces the goal.
  • Fast logging — core actions in under 10 seconds.
  • AI assisted — supported, never overwhelmed.
  • Minimal load — no clutter, no vanity metrics.
  • Mobile first — most interactions happen on a phone.

05 · UX rationale

Why it's built this way

Photo-first meal logging

The #1 reason people abandon trackers is manual entry. We lead with the camera and let AI estimate items, portions, and macros — surfacing a confidence indicator per item so the user only corrects the uncertain ones. Confirm is a single tap.

Progressive overload, decided for you

Each exercise shows last vs a suggested target. Hit the top of the rep range on all sets → load goes up (~2.5 kg upper / 5 kg lower). Miss it → weight holds so reps build first. The user never has to plan progression.

Trend over daily noise

Weight screens emphasize the 7-day average and a goal line, not the daily number, so water-weight swings don't feel like failure. Projection ("Sep 21, 32 days early") keeps the long game visible.

Coach, not chatbot

The default Coach view is a briefing + insight cards + concrete actions — proactive, scannable. Conversation is available but secondary. The coach references real data and adapts the plan (e.g. holding load for a tight shoulder).

Missions turn goals into execution

A daily checklist with completion %, streaks, and progress bars converts an abstract 30 kg goal into seven concrete things to do today. Streaks drive return visits without nagging.

Mobile-native, not shrunk desktop

Mobile is single-column, thumb-driven, full-bleed flows for camera/session. Desktop is a multi-column command center with a persistent rail and table-dense workout/weight views — each laid out for its form factor.
